Find sellers, register contact details and follow up agreement acceptance.

## Start with the seller
1. Search for the seller before registering a new person. Open the profile for contact details, items and agreements.
2. If the store uses self-registration, review incoming applications in the registrations view before approving them.
3. For store email, choose recipients and check the selection and displayed consent before sending.

## Agreements and acceptance
An owner or administrator can publish a new agreement version. Sellers can accept it in the seller portal. Staff can instead record a reference to acceptance already obtained elsewhere, such as a signed paper.

Select the correct agreement version when following up missing acceptance. If the store requires an agreement, acceptance is needed before receiving the drop-off.

> Printing an agreement does not accept it. New versions do not change earlier acceptance evidence or receipts.
